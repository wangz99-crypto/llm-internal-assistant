Modes (plain English)

            

              
Hybrid

              
Best for most questions. Uses internal knowledge first; adds a clear explanation when needed.


              
Verified

              
Best for compliance. Answers only when internal sources support the response.


              
Assist

              
Best for drafting. More free-form help. (In this hosted demo, advanced LLM is limited; a GPU-backed version is available in private deployment.)
