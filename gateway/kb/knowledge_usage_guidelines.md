# Knowledge Usage Guidelines

## Hybrid Mode
Best default option.
- Uses internal documents when available.
- Adds explanation for clarity.
- Balanced for speed and reliability.

## Verified Mode
Strict compliance mode.
- Answers only when supported by internal sources.
- Avoids speculative responses.
- Recommended for audits or policy-sensitive tasks.

## Assist Mode
Drafting and brainstorming.
- Helpful for general writing tasks.
- May rely less on internal references.
- In private deployments, this can be backed by a larger GPU-based language model.

---

## When to Use Each Mode

- Policy or compliance question → Verified
- Operational question → Hybrid
- Drafting communication → Assist
